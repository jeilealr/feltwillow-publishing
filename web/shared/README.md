# Shared web resources

**State: spec_only.** Planned contents (only when a renderer is implemented):
- `tokens.css`: colours, type scale, spacing; contrast checked.
- `i18n/<lang>.json`: reviewed UI strings for every offered language (navigation, Listen, Transcript,
  Skip to content, 404 text).
- `fonts/`: only fonts whose licence allows web embedding, recorded in the licensing register.
- `screenshot-checklist.md`: the one checklist used to compare every renderer.

No story text, provider IDs, media or production references live here.
